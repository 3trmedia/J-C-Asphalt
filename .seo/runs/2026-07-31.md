## Technical fixes applied
1. **Canonical domain mismatch (root cause of split indexing).**
   `astro.config.mjs` had `site: 'https://jcasphaltpaving.com'` (apex) while
   Vercel serves the live site on `www`. GSC had the homepage indexed twice:
   apex at position 2.87 (757 impr), www at position 16.88 (509 impr) — one
   page's ranking signal split in half. Fixed `site` to
   `https://www.jcasphaltpaving.com`; canonical, og:url, sitemap, and JSON-LD
   `url`/`image` all now emit www. Verified in build output.
2. **Trailing-slash duplicates** (`/about/`, `/services/concrete/`) — added
   permanent redirects to the slash-free canonical form in `vercel.json`.
3. **Legacy anchor URLs** (`/#about`, `/#projects`, `/#quote`, `/#services`)
   — investigated and found these can't be redirected server-side (hash
   fragments never reach Vercel; the browser strips them before the request
   goes out). They already resolve to the homepage as-is. No code fix
   possible or needed — flagged for Ben to request removal in GSC if he
   wants them out of the index faster than natural decay.
4. **Self-serving `aggregateRating`** — removed from the sitewide
   HomeAndConstructionBusiness JSON-LD (was hardcoding 4.2/5 reviews with no
   on-page review content backing it, a Google guideline violation, and
   plausibly why Search Appearance came back empty).
